КАК ЗАПУСТИТЬ

1. Открой папку frontend_team_final в VS Code.
2. Запусти index.html через Live Server.
3. Снизу есть три вкладки:
   - Главное
   - Асхат
   - Ерасыл

Во вкладке «Главное» находятся два участника:
сначала круглая фотография-аватарка, потом ФИО.

Если нажать на участника в списке или на нижнюю вкладку с его именем,
откроется его резюме на этой же странице.

В проекте только одна HTML-страница.
Переключение сделано через JavaScript.
